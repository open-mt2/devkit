# T3.1 — Windows packaging

- agent: agent-06 (DeepSeek V4.1 Flash)
- date: 2026-10-31
- command: `OPENMT2_DIST_DIR=dist-linux scripts/build.sh` + `OPENMT2_DIST_DIR=dist-windows scripts/build-windows.sh` + `diff -rq dist-linux dist-windows` + `python3 scripts/dist-diff.py dist-linux dist-windows` + Wine smoke
- before: `build-windows.sh` copied the binaries and the raw `bin/pack`
  directories but never built the archives (`dist/pack` had only `Index`), did
  not ship `libstdc++-6.dll` / `libgcc_s_seh-1.dll` (both are `DT_NEEDED`, so
  the `.exe` failed to start outside the build image), and duplicated the asset
  copy logic of `build.sh`.
- after: both targets run the same `copy-assets.sh` + `pack-assets.sh`; the
  Windows tree gets the two MinGW runtime DLLs next to `python27.dll` /
  `msvcr90.dll`; `metin2client.exe` boots under Wine for 30 s. Asset trees are
  byte-identical: `diff -rq` reports **zero content differences**, only
  platform-only files (1032 lines, all "only in").
- notes:
  - **Diff summary:** 286 identical files (assets, treecache, all 102 pack
    archives); 4 452 expected platform-only files; **0 unexpected**
    (`python3 scripts/dist-diff.py`). Expected = Linux binary + `metin2`
    symlink, `runtime/` and the #115 stdlib overlay under `lib/`, Windows
    `.exe` + root runtime DLLs.
  - `python3 scripts/dist-diff.py dist-linux dist-windows` is the automatable
    form of the sheet's `diff -r`; it fails on any non-runtime difference
    (asset drift, a missing game file, or a content mismatch).
  - SDL2 is linked statically (`libSDL2.a`, T2.3), so there is no `SDL2.dll`
    in the tree; `objdump -p metin2client.exe` lists `python27.dll`,
    `libstdc++-6.dll`, `libgcc_s_seh-1.dll` and no SDL2 import.
  - `build-windows.sh` gained `--skip-pack` and `OPENMT2_DIST_DIR`, matching
    `build.sh`; `config.exe` is copied when the target exists (the current
    CMake graph has no Config target, same as Linux).
  - Tests: `tests/test_dist_diff.py` **5/5**, `tests/test_windows_harness.py`
    **6/6** (added shared-assembler and runtime-DLL assertions),
    `tests/test_pack_assets.py` **7/7**.
  - Wine smoke: `wineboot -u` once, then `timeout 90 wine metin2client.exe`
    under Xvfb; process alive at 30 s, `syserr.txt` only has the known
    non-fatal `CMSWindow::Cursors Create Error`.
  - `scripts/dist-diff.py` treats anything Linux-only under `lib/` as the
    interpreter overlay because both targets copy `lib/` with the same script
    before the overlay; a missing *shared* file is reported as content drift.
