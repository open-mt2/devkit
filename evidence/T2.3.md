# T2.3 — Cross-build the Windows dependency set

- agent: agent-06 (DeepSeek V4.1 Flash)
- date: 2026-10-31
- command: `scripts/build-windows-deps.sh` + `docker run … openmt2/client windows` configure + header/link probes
- before: the Windows configure stopped at `Could NOT find OpenGL` (host-only libraries) and `Package 'miniaudio' … not found`; nothing was cross-built for `x86_64-w64-mingw32`, and Debian ships no mingw packages for these libraries.
- after: `scripts/build-windows-deps.sh` cross-builds the pinned set into `/opt/openmt2/win64` (baked by the dockerfile). The configure resolves every dependency from that prefix; the remaining `NOTFOUND` is `PYTHON_LIBRARIES`, which is T2.4's scope.
- notes:
  - **Pinned set (sha256-checked):** zlib 1.3.1, lzo 2.10, libzip 1.10.1, SDL2 2.30.9, miniaudio 0.11.25. libjpeg is intentionally absent (T2.2 replaced it with `stb_image_write`).
  - **Artifacts:** `lib/libz.a`, `lib/liblzo2.a`, `lib/libzip.a`, `lib/libSDL2.a`, `lib/libSDL2main.a`, `lib/libminiaudio.a`, plus headers and `.pc` files.
  - **Wiring:** `cmake/toolchain-i686-windows-gnu.cmake` puts `OPENMT2_WIN64_DEPS_PREFIX` (default `/opt/openmt2/win64`) first in `CMAKE_FIND_ROOT_PATH`; `docker/root/cmake/Platform.cmake` adds its `include/` and `lib/` on Windows; `scripts/build-windows.sh` points `PKG_CONFIG_LIBDIR` at the prefix; the dockerfile runs the script in its own layer before the package fetch.
  - **Verification (container `openmt2/client:79`, prefix mounted at `/opt/openmt2/win64`):**
    - `scripts/build-windows-deps.sh` exits 0 and lists the six `.a` files.
    - Windows configure log: `Found OpenGL: opengl32`, `Found miniaudio, version 0.11.25`, no zlib/lzo/libzip errors.
    - `CMakeCache.txt`: `LZO_LIBRARY=/opt/openmt2/win64/lib/liblzo2.a`, `pkgcfg_lib_LIBZIP_zip=/opt/openmt2/win64/lib/libzip.a`, `pkgcfg_lib_MINIAUDIO_miniaudio=/opt/openmt2/win64/lib/libminiaudio.a`.
    - Header probes with `x86_64-w64-mingw32-g++ -I/opt/openmt2/win64/include`: `<lzo/lzo1x.h>`, `<SDL2/SDL.h>`, `<zip.h>`, `<zlib.h>`, `<miniaudio/miniaudio.h>` all compile.
  - **Not yet green (out of T2.3 scope):** the Windows build still stops at
    `PYTHON_LIBRARIES` (T2.4) and, once that is in place, at Windows portability issues the
